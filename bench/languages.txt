# Per-language floors for `glasir langcheck --check`.
#
# `bench/baseline.txt` guards retrieval on *this* tree, which is Rust: six of
# its seven floors read nothing else, so a scanner that stopped finding Julia
# definitions moves none of them. These floors guard extraction instead.
#
#   <language>  <min defs/kLOC>  <min edges/kLOC>  <max % on <module>>
#
# **They are measured against `bench/langs`, not against a corpus of foreign
# code**, and that is the whole reason this file can be a CI gate. The corpus
# these numbers were calibrated with is 1.8 GB of clones under `tmp/`: GPL in
# one case, unclear in five, and every permissive one would mean carrying its
# copyright notice. `bench/langs` is 25 files of our own, one per language,
# all writing the same four functions — a charge that refuses over a limit —
# so a number that differs between two languages is a scanner difference
# rather than a program difference.
#
# **A 25-line fixture catches what 720,000 lines catch.** Sabotaging Go's
# `func` keyword, which is the shape a new language version produces, takes
# the fixture from 0% on `<module>` to 100%; on the real corpus it took 3% to
# 99%. What does *not* transfer is the yield: definitions per 1,000 lines are
# 208 on the fixture against 45 in gin, because a fixture is all signature and
# no body. Hence the floors below sit at 60% of the fixture's own measurement
# — they check that extraction still happens, not that a corpus is normal.
#
# **The third number is the sharp one.** A yield figure moves by a third when
# a corpus changes mix — gin measures 81, 112 and 97 definitions per 1,000
# lines across three of its own subdirectories — while `<module>` stays at
# 1-2% in all three. It is the share of references with no enclosing
# definition, and a scanner that stops recognising a keyword has nothing else
# to attribute them to.
#
# Ceilings are per language on purpose. Erlang's `-export` and `-define` are
# file-level attributes and Julia's `module ... end` legitimately encloses
# nothing, so both sit above zero here; on real code a C header is 70% and
# RSpec's blocks are 100%, which one global bound could not express.
#
# Measured values, not goals. Raise one in the same commit that improves it;
# lower one only with the reason. Run `glasir langcheck bench/langs` to see
# what the numbers are now, and `glasir langcheck tmp/corpus` against real
# code when the clones are present.
