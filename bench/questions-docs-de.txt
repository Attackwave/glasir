# The same eight questions as questions-docs.txt, asked in German.
#
# Deliberately translations rather than new questions, and with the same
# expected sections: what is being measured is the *language*, not the phrasing.
# Two sets that asked different things would confound the two, and the whole
# point is a clean before/after for C.4.
#
# Why this matters beyond this tree: Pawelka and Juergens measured ten industry
# systems against thirteen open-source ones. Half the industry systems carry
# 50-90% non-English comments and three carry 28-45% non-English identifiers;
# the open-source projects carry essentially none. This tree is the same shape —
# German documentation over English code — so it is a fair small-scale stand-in
# for the case the roadmap's C.4 is about.
#
# The translations keep the vocabulary a German speaker would actually use, not
# a word-for-word rendering that smuggles the English terms back in. "Schichten"
# rather than "Layers", "Anfrage" rather than "Request" — otherwise the set
# would measure nothing, because the English term is what the index already has.
