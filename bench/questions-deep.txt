# Retrieval ground truth for a *deep* tree: `bench/deep`.
#
# The four sets beside this one all measure `glasir` itself — a flat Rust
# repository where `src/` is one level and a file name is usually a subsystem
# name. Three findings the audit could not decide were blocked on exactly that:
# the path in tokenization (step 4), `B = 0` (step 8c) and the hub exclusion
# (step 8a) each win on one shape of tree and lose on the other, and there was
# only one shape to measure against.
#
# `bench/deep` is that second shape: layered (api / services / schemas / models
# / core), two languages, six to eight path segments, and the same handful of
# verbs — `create`, `get`, `list` — defined three times each across different
# directories. The proportions are calibrated against a real 409-file
# SvelteKit/FastAPI monorepo, where `create` is defined in 11 files, `get` in
# 11 and `list` in 9, and 78% of the search index is path rather than
# identifier.
#
# It reproduces the damage that motivated it. `create contact` ranks
# `AddressCreate` and `BankAccountCreate` — schema classes that never say
# "contact" and only inherit it from `schemas/contact.py` — above
# `api/v1/contacts#create_contact`, with nine hits inside 0.2 BM25 points.
#
# Format as in `questions.txt`: the question, then the symbols an answer must
# reach. Chosen by reading the code, not by running either method.
