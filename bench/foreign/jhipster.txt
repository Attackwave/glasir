# jhipster/jhipster-sample-app — HTTP calls across languages: an Angular
# client (TypeScript) and a Spring server (Java) in one repository.
#
# Read by hand, pair by pair: the client builds its URL from a field,
# `resourceUrl = \`${serverApiUrl}api/bank-accounts\``, then
# `this.http.get(\`${this.resourceUrl}/${id}\`)`; the server joins the
# class's `@RequestMapping("/api/bank-accounts")` with the method's
# `@GetMapping("/{id}")`. The verb has to agree: find and delete both hit
# `/{id}`, one with GET and one with DELETE.
