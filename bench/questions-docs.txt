# Ground truth for the documentation in this tree, kept separate from
# questions.txt on purpose.
#
# questions.txt asks "which code does this" and its answers are symbols. These
# ask "what was intended, and why" — questions whose honest answer is a
# document section, not a function. Mixing them would have made the code
# benchmark punish every documentation node for occupying a slot, which is what
# it did when documents were first indexed: prose recall fell 58% -> 50% with no
# question in the set that a document could answer.
#
# The two files are measured separately for that reason. A change that helps
# one and hurts the other is a trade to decide, not a regression to revert.

# The overview section names the layers; the layer sections are the layers.
# Either answers the question, so both count — pinning only the overview made
# the set measure a formatting choice rather than whether the answer was found.
