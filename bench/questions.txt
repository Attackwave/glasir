# Format: the question, then the symbols an answer must reach, one per line,
# indented. A blank line ends the block, `#` is a comment.
#
# The symbols are what someone would actually have to read to answer, chosen by
# reading the code rather than by running either method — otherwise the set
# would be a description of whichever tool it was derived from. Where a
# question has one obvious answer plus supporting context, only the load-bearing
# symbols are listed: crediting a tool for finding everything adjacent would
# make precision meaningless.
